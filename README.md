# Sales & Revenue Analysis Dashboard

## Project Description
This project analyzes sales and revenue data using Python.

## Features
- Read sales data from CSV
- Calculate total sales
- Calculate total revenue
- Generate report
- Create charts

## Technologies Used
- Python
- Pandas
- Matplotlib

## Project Structure
sales-revenue-dashboard/
├── data/
├── dashboard/
├── reports/
├── images/
├── main.py
├── requirements.txt
└── README.md

## How to Run

```bash
pip install -r requirements.txt
python main.py
```
